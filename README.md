# 순천향대학교 졸업 길잡이

순천향대학교 AI·빅데이터학과 졸업요건 과제용 **Streamlit 챗봇**입니다. 제공된 PDF에서 근거를 찾고, 수강 과목·활동 입력은 Python 규칙 엔진으로 계산합니다. 기본 선택은 AI·빅데이터학과 / 2022학번이며 **실제 학생 기록·점수는 미리 입력하지 않습니다.**

## 교수님은 여기서 시작하세요

**공개 원본:** https://graduation-chatbot-production-bbee.up.railway.app/

공개 주소 → **가입 없이 챗봇 시작**을 누르세요. Python 설치·회원가입·학교 비밀번호가 필요 없습니다. **교수용 과제 평가**와 [약 3분 확인 순서](PROFESSOR_DEMO.md)에서 PDF 질문, 추가 문서 검색, 수강 파일·활동 진단을 확인할 수 있습니다.

| ZIP의 파일 | 용도 |
|---|---|
| `챗봇_시작.html`, `교수님_확인.html`, `교수님_확인하기.url` | 인터넷으로 공개 원본 챗봇을 여는 입구 |
| `오프라인_보조체험.html` | 설치·인터넷 없는 별도 JavaScript 간편 체험. Python·FAISS·LLM을 실행하지 않음 |
| `원본프로젝트/` | 이 README와 실제 Python 소스·PDF·규칙·테스트 |
| `최종검수보고서.md`, `SOURCE_VERSION.json`, `검증기록/` | 실제 배포·시험 결과, 커밋과 실행 파일 지문, 미검증 범위 |

시작 HTML 자체에서 Python이 실행되는 것은 아닙니다. **새 디자인과 전체 기능은 공개 원본 또는 아래 방법으로 실행한 Python 앱에서 확인**하세요. 이클래스에는 제출 ZIP과 공개 주소를 함께 제출합니다. 학교 이클래스의 실제 제출 버튼은 사용자가 눌러야 합니다.

## 1. 구현한 과제 기능

| 기능 | 동작과 근거 |
|---|---|
| PDF 단독 RAG | 제공 PDF만 검색합니다. 학과·학번별 표를 구조화하고 문서명·실제 페이지를 표시합니다. 다른 PDF나 홈페이지를 검색하지 않습니다. |
| 다중 문서 RAG | 현재 계정 또는 교수 체험 세션에 PDF를 추가하고 통합 검색합니다. 적용 학과·학번을 확인하고 서로 다른 근거를 구분합니다. |
| 개인별 졸업요건 진단 | CSV/XLSX·직접 입력과 활동·인증·공식 인정 점수를 규칙 엔진으로 검사합니다. 영역별 점수·필수 항목·부족한 조건을 표시합니다. |

**다면적 졸업인증 충족 예상**과 **전체 졸업 확정**은 다릅니다. 전체 졸업학점·필수 교양·대체과목·공식 학생 이수 규정은 제공되지 않아 전체 졸업 확정은 **확인 필요**로 표시합니다. 새 PDF가 검색에 포함돼도 계산 규칙은 자동으로 바뀌지 않습니다.

추가 공식 PDF는 화면에서 업로드하면 코드 수정 없이 검색에 반영됩니다. 적용 학과·학번을 문서에서 확인하며, 충돌하는 근거는 구분해 표시합니다. **자동 진단 규칙**의 변경은 원문 검수 후 별도로 반영해야 합니다. 대문자 `.PDF` 파일도 등록할 수 있고 같은 내용의 중복 등록은 한 파일로 처리합니다.

첫 화면의 질문 버튼으로 시작하거나 `나는 AI·빅데이터학과 2022학번인데 졸업하려면 뭐가 필요해?` → `그럼 코딩역량인증은?` → `그거 안 하면 졸업 못 해?`처럼 질문할 수 있습니다. 현재 대화의 주제·학과·학번만 연결하며 선택 학과·입학연도 변경 또는 대화 지우기 이후에는 이전 문맥을 적용하지 않습니다. 검색 방식·생성형 사용 여부·실행 버전은 접힌 **교수용 기술 검증 · 고급 설정**에 있습니다. 기본 화면에서도 생성형 AI 사용 여부를 구분합니다.

## 2. 처음 설치하고 실행하기

공개 주소를 이용하면 설치가 필요 없습니다. 소스를 직접 실행하려면 64비트 **Python 3.12**와 인터넷을 준비합니다. 제출 ZIP은 전체 압축 해제하고 `원본프로젝트` 폴더에서 실행하세요. 소스 전용 ZIP은 `graduation-rag-chatbot` 폴더입니다.

Windows PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --global.developmentMode false
```

가상환경 활성화나 시스템 실행 정책 변경은 필요 없습니다. `py`가 없거나 `No suitable Python runtime found`가 나오면 Python 3.12를 설치하고 새 터미널을 열거나 설치한 Python의 전체 경로를 사용하세요. 가상환경 생성에 실패했다면 뒤의 `.venv` 명령부터 다시 실행하면 안 됩니다.

macOS/Linux:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py --global.developmentMode false
```

브라우저에서 `http://localhost:8501`을 엽니다. 터미널을 열어 두고 사용하며 종료는 Ctrl+C입니다. 최초 설치와 임베딩 모델 다운로드는 크기·시간이 클 수 있습니다.

Windows의 **START_CHATBOT.cmd**는 `.venv`를 우선 사용해 빈 포트와 서버 준비 상태를 확인한 뒤 브라우저를 엽니다. 이 개발 컴퓨터의 기존 환경을 사용하는 보조 경로도 있지만, 다른 PC에서는 위 설치가 먼저 필요합니다. 정상 실행 후에는 코드 파일 `app.py`를 더블클릭할 필요가 없습니다.

클라우드 실행 진입점은 `python deploy.py`입니다. `PORT`를 받아 `0.0.0.0`으로 실행하며, Docker 배포·환경변수는 [DEPLOYMENT.md](DEPLOYMENT.md)에 정리했습니다. 현재 공개 서버·ZIP의 상태는 제출 검수 보고서가 기준입니다.

## 3. 검색 모드와 생성 모드

| 설정 | 실제 동작 |
|---|---|
| API 없음, FAISS 꺼짐 | 검수된 PDF 표·범위 필터·키워드 검색과 정형 답변. 별도 로컬 생성 모델은 없음 |
| **다국어 임베딩 + FAISS** 기본 켬 | 같은 다국어 MiniLM의 고정 버전 ONNX int8로 실제 벡터 검색. 첫 질문 메뉴에서 준비하며 진단 화면만 볼 때는 로드하지 않음 |
| **LLM 답변 사용** 켬 + 유효 API 키 | 검색 근거·질문·적용 범위를 생성 모델에 전달. 근거 밖 수치·잘못된 인용·오류가 감지되면 대체 답변 또는 확인 필요 |

LLM 사용은 선택 사항이며 **점수 계산에는 LLM을 사용하지 않습니다.** 표 구조화는 사람이 대조한 학과·학번 규칙을 사용하며 모든 PDF 표를 자동으로 완벽히 해석하는 엔진은 아닙니다.

기본 모델은 `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`의 `e8f8c211226b894fcb81acc59f3b34ba3efd5f42` 버전, `onnx/model_quint8_avx2.onnx`입니다. 평균 풀링·정규화, 길이128·배치4·CPU 스레드1을 사용합니다. 공개 Docker 이미지는 빌드 때 모델을 내려받아 실행 중에는 오프라인 캐시를 사용합니다. 모델 하나만 공유하고 개인 문서 인덱스와 질문 임베딩 캐시는 로그인/체험 세션에 둡니다. `RAG_VECTOR_DEFAULT=0`이면 명시적으로 키워드 모드, `EMBEDDING_BACKEND=torch`이면 기존 PyTorch CPU 방식입니다. 메모리가 제한된 서버에서는 기본 ONNX 방식을 사용하세요. 모델 준비 실패는 화면에 표시하고 원문 검색으로 대체합니다.

Windows 실제 8문항 평가에서 PyTorch 방식 약1,222MB, ONNX 방식 약519MB의 인덱스 준비 후 프로세스 RSS를 관측했습니다. 두 방식 모두 학과·학번·페이지와 기대 답변 8/8을 통과했습니다. 이는 작은 검증집합의 결과이며 일반 정확도나 Railway 실측을 대신하지 않습니다. 공개 서버 측정은 최종 검수 보고서에 별도로 기록합니다.

선택적 API 설정:

```powershell
Copy-Item .env.example .env
```

`.env`에서 `OPENAI_API_KEY`와 계정에서 사용 가능한 `OPENAI_MODEL`을 설정합니다. 키는 공유하지 마세요. 기본 예시는 `gpt-4.1-mini`이며 모델 이름을 사용할 수 없다면 바꿔야 합니다. `OPENAI_MAX_OUTPUT_TOKENS=800`은 128~2000 범위의 요청별 출력 제한입니다. 30초·재시도0으로 제한하며 총 요금 한도는 API 계정에서 별도 설정해야 합니다. 외국어 질문의 번역·생성·답변 번역은 여러 요청이 될 수 있습니다.

**실제 API 연결에 성공했는지는 최종검수보고서를 확인하세요.** 유효 키가 없어 실행하지 못한 검증은 미검증으로 남깁니다. 모의 API 테스트는 실호출 성공 증거가 아닙니다.

## 4. 메뉴와 PDF 원문 확인

- **PDF 단독 RAG:** 원본 한 개만 검색합니다. 예: `졸업하려면 뭘 해야해?`, `코딩역량 인증제 조건이 뭐야?`.
- **다중 문서 RAG:** 문서를 등록한 뒤 새 내용으로 질문합니다. PDF는 30MB 이하, 텍스트 추출 가능해야 합니다. 손상·암호화·스캔 이미지 PDF는 안내하며 OCR 엔진은 포함하지 않습니다.
- **학과·졸업 통합 상담:** PDF와 확인일이 있는 공식 학과 홈페이지 교육과정·연락처를 함께 참고합니다. 실시간 전체 웹 검색은 아닙니다.
- **졸업요건 진단:** 수강 목록과 활동·인증·공식 점수를 입력한 뒤 진단합니다. 미입력·미확인과 확정 미이수를 구분합니다.
- **진단 결과:** 영역별 점수, 필수 과목·활동, 다음 행동과 결과 JSON/CSV를 확인합니다. **입력 수정하기**로 돌아가거나 **진단 결과로 상담하기**로 부족 활동·준비 순서·입력한 이수 과목·가장 부족한 영역을 질문합니다. 자격증 취득 가정은 Python 판정기로 다시 계산하며 원래 입력·결과를 변경하지 않습니다. 입력·규칙·계산 근거 PDF 변경 후 지난 결과임을 알립니다. 검색 메뉴 변경 자체는 진단을 오래된 것으로 처리하지 않습니다.
- **교수용 과제 평가:** 실제 학생 기록을 사용하지 않는 시연 자료와 가상 사례로 확인합니다.

답변의 **근거 원문 보기**는 검색된 텍스트입니다. **출처 PDF 페이지 확인 → 원문 p.N 열기**는 실제 PDF 해당 쪽의 이미지와 한 페이지 추출 PDF입니다. 원본 전체 PDF도 내려받을 수 있습니다. 원본 페이지 번호는 1부터 시작하며, 한 페이지 추출 파일 내부에서는 그 페이지가 1쪽으로 보입니다.

출처 파일은 현재 검색 범위에서 허용된 PDF 폴더만 읽습니다. 출처가 홈페이지이면 PDF 이미지 대신 원래 안내 링크를 확인하세요. 출처 파일·페이지가 없으면 임의로 다른 파일을 열지 않습니다.

한국어·English·简体中文·日本語를 상단에서 선택합니다. 한국어 과목명·인증 이름과 원문 근거는 함께 유지합니다. 기본 주제는 API 없이 정형 번역을 제공하며 모든 자유 문장의 완전한 번역을 보장하지 않습니다.

## 5. 수강 과목·활동 입력과 진단

필수 열은 `과목명`, `이수 여부`입니다. `examples/courses.csv`는 빈 양식입니다. CSV는 UTF-8(BOM 가능)·CP949, XLSX는 첫 시트를 읽으며 5MB 이하입니다. `.xls`는 지원하지 않습니다.

```csv
과목명,이수 학기,취득 학점,이수 여부,성적,교과 영역
예비창업설계,2026-1,3,이수,P,전공
가상미이수과목,2026-2,3,미이수,,전공
```

- 이수: `이수`, `완료`, `예`, `true`, `1`, `y`. 미이수: `미이수`, `아니오`, `false`, `0`, `n`, 빈 값.
- 성적 F/NP/U는 이수 표시가 있어도 제외합니다. 중복 과목은 한 번만 인정합니다. 띄어쓰기·유니코드만 정규화하며 유사 과목·대체 인정은 임의로 확정하지 않습니다.
- 취득 학점은 졸업인증 점수로 바꾸지 않습니다. 중핵교양의 개별 과목 목록은 PDF에 없어 과목명과 공식 영역 이수 확인을 함께 입력합니다.
- 활동은 해당 항목의 체크박스·횟수·인증 수준·자격증·공식 점수로 입력합니다. 사용자가 공식 인정 기록을 확인했다는 자기신고이며 학교 시스템과 실시간 연결하지 않습니다.
- **이수 내역을 모두 입력했습니다**를 체크하면 미선택을 미이수로 처리합니다. 미체크 시 부족한 정보는 확인 필요입니다. 잘못된 파일은 수정할 때까지 진단을 막습니다.

AI·빅데이터학과 **2022학번 / 원본 PDF 5쪽**:

| 영역 | 필요 점수 | 필수 조건 |
|---|---:|---|
| 대학공통 | 45 | 인간사랑·ASP·자기주도상담·자기개발과전공탐색·졸업필수활동·현대기본영어·봉사학습 |
| 교과 | 10 | 예비창업설계5, 중핵교양 국제사회언어영역 택1 5 |
| 비교과지정 | 21 | 학과활동5, 권장 자격증/경진대회6, 코딩Level2 이상5, AI·SW전공역량졸업인증5 |
| 비교과미지정 | 19 | 공감5, 창의4, 글로벌10 |
| 합계 | **95** | 총점·각 영역·필수 항목을 모두 검사 |

학과활동은 회당1점, 필요점수5점이 상한입니다. 권장 자격증은 PDF의 정확한 이름으로 선택합니다. 경진대회는 PDF에 참가3~10·수상10~30 범위만 있으므로 대회별 공식 인정 점수 확인이 필요하며 참가·수상을 임의 합산하지 않습니다. 자율활동은 인재상별 공식 인정 점수를 입력하고 다른 영역의 초과점수로 부족을 상쇄하지 않습니다.

2023학번 등은 TOPCIT 여부·영역 구성이 다르므로 선택 학번의 표를 적용합니다. 문서에 없는 학과·학번은 확인 필요입니다. 전체 졸업학점·필수 교양·공식 대체과목·최신 확정 인증표가 추가로 필요합니다.

## 6. 문서 현황과 합성 시연 파일

공식 참고 링크: [학과 홈페이지](https://home.sch.ac.kr/aibigdata/index.jsp), [교육과정](https://home.sch.ac.kr/aibigdata/02/0101.jsp). 홈페이지는 현재 실시간 검증 결과가 아니라 위 확인일의 스냅샷입니다. 제공된 개인 학사화면과 PDF의 영역 배치 차이는 학과에 확인해야 하며 개인 화면을 새 규정으로 일반화하지 않습니다.

## 7. 검증 방법과 결과 읽기

```powershell
.\.venv\Scripts\python.exe -m pytest -q
$env:RUN_EMBEDDING_TEST="1"
.\.venv\Scripts\python.exe -m pytest -q
```

macOS/Linux에서 실제 모델을 포함하려면 `RUN_EMBEDDING_TEST=1 .venv/bin/python -m pytest -q`를 사용합니다. 최초 모델 다운로드에는 인터넷이 필요합니다. Windows 네이티브 라이브러리와의 충돌을 피하기 위해 테스트는 `--capture=sys`를 사용합니다.

| 검증 | 실제 사용한 것 | 한계 |
|---|---|---|
| 원문·페이지·규칙 | 실제 제공 PDF와 좌표·문구·5쪽 추출 대조 | 최신 확정 규정·개인 승인 기록 검증은 아님 |
| 벡터 검색 | 실제 다국어 모델·FAISS를 켠 검사 | 생성 API 검증과 별개 |
| 업로드·계산·UI | 합성 PDF/CSV/XLSX, 가상 활동, Streamlit AppTest 및 기록된 공개 서버 흐름 | 실제 학생 기록을 조회하지 않음 |
| API 오류·출처 검사 | 모의 API 응답·예외와 키 없는 경로 | 유효 키의 실호출 성공이 아님 |
| 배포·제출 | 기록에 명시된 커밋의 공개 접속과 압축 해제본 실행·파일 지문 | 영구 접속·모든 PC·실제 휴대폰 보장은 아님 |

정확한 통과 수·실행 조건·미검증 항목은 `test-results.xml`과 제출 바깥 `최종검수보고서.md`가 기준입니다. `검증기록/ZIP실행검사.json`의 커밋·지문이 `SOURCE_VERSION.json`과 같아야 현재 ZIP의 실행 증거입니다. 의존성 설치 기록은 현재 커밋 실행 증거와 구분합니다. 테스트 개수가 모든 질문의 정확성을 보장하지 않습니다.

`colab_demo.ipynb`는 실습용이며 실제 Colab 런타임 실행은 별도 미검증입니다. `scripts/validate.py --embedding`은 전체 테스트와 HTTP 기동 점검을 실행합니다.

## 8. 계정·저장·호스팅

학교 SSO와 별개의 자기신고형 앱 계정입니다. 학생은 학번, 교수·평가자는 평가용 아이디로 개인 계정을 만들 수 있습니다. 앱 전용 비밀번호를 사용하며 기본 계정·비밀번호는 없습니다. 비밀번호는 무작위 salt·PBKDF2 600,000회로 해시하고 로그인 실패를 제한합니다.

계정·진단은 `GRADUATION_APP_DATA_DIR` 또는 `.local/`의 SQLite에 저장합니다. 계정별 PDF를 분리하고, 교수 무가입 입력·업로드는 세션 전용으로 체험 종료 시 정리합니다. 문서 내용을 포함하는 개인 인덱스를 공용 모델 캐시와 구분합니다. SQLite·.env·실제 기록·캐시를 공개 저장소나 제출 ZIP에 넣지 마세요.

**Codex와 개인 PC를 꺼도 Railway 앱은 서버에서 실행됩니다.** 로컬 `localhost` 앱은 실행 PC·터미널이 켜져 있어야 합니다. 체험 플랜의 남은 기간·사용량·메모리와 영구 저장소 여부는 최종 보고서의 관측 시점을 확인하세요. 영구 접속을 보장하지 않으며 결제·유료 업그레이드는 사용자 승인 없이 진행하지 않습니다. 서버 교체 시 로컬 디스크의 계정·기록이 사라질 수 있습니다.

## 9. 문제 해결

| 증상 | 확인 방법 |
|---|---|
| 새 디자인 대신 다른 화면 | 공개 원본 주소나 `챗봇_시작.html`을 사용하고, 오프라인 보조 체험과 구분 |
| 실행 명령 불가·모듈 없음 | Python3.12 가상환경 생성 성공 후 해당 Python으로 requirements 설치 |
| 포트 사용 중 | `--server.port 8502 --global.developmentMode false`로 실행하거나 START_CHATBOT 사용 |
| 모델 준비 실패 | FAISS 토글을 끄고 원문 검색·계산 사용, 네트워크 확인 후 재시도 |
| PDF 텍스트 없음 | 텍스트 PDF 또는 OCR 처리본 필요 |
| CSV/XLSX 오류 | 필수 헤더·첫 시트·인코딩·이수 여부·5MB 제한 확인 |
| API 오류 | 키·모델·연결·잔액 확인, 키 없이 검색·계산 가능 |
| 원문 페이지 없음 | 현재 세션의 원본 파일·페이지를 확인하고 필요한 PDF를 재등록 |
| 지난 진단 안내 | 입력·규칙·문서가 변경됐으므로 같은 학과·학번에서 재진단 |
